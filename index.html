구글 스프레드시트 연동

💡 구글 시트 URL(docs.google.com/...)을 그대로 입력하거나, Apps Script 웹 앱 URL(/exec)을 입력하세요.
구글 스프레드시트 주소를 입력하고 [시트에서 불러오기]를 누르세요.
⚠️ 시트 연결 실패(Failed to fetch) 해결 방법:
  1. 구글 스프레드시트 링크를 직접 입력한 경우:
    해당 구글 시트 우측 상단 [공유] > 일반 액세스를 '링크가 있는 모든 사용자(뷰어)'로 설정해야 브라우저에서 데이터를 읽어올 수 있습니다.
  2. Apps Script 웹 앱 URL을 입력한 경우:
    Apps Script 배포 시 '액세스 권한'이 반드시 '모든 사용자(Anyone)'로 설정되어 있어야 합니다. ('나만'으로 되어 있으면 Google 로그인 보안 차단으로 인해 Failed to fetch가 발생합니다.)
  3. URL 끝이 /dev로 되어 있는 경우:
    /dev는 테스트 주소이므로 권한 오류가 발생합니다. [배포] > [배포 관리]에서 /exec로 끝나는 웹 앱 URL을 복사하세요.
  4. 가장 빠른 해결책: 상단 [📋 시트 셀 직접 붙여넣기] 탭을 누른 후 구글 시트 셀을 복사(Ctrl+C)하여 붙여넣으면 즉시 100% 정상 적용됩니다.

구글 시트에서 학생 이름과 역할이 적힌 셀 영역을 드래그하여 복사(Ctrl+C)한 후, 아래 입력창에 붙여넣기(Ctrl+V)하세요.

※ A열: 학생 이름, B열: 역할 이름 (열 헤더가 있어도 자동으로 감지합니다)
💡 Apps Script 배포 필수 체크리스트 (Failed to fetch 방지)
  • 1. 스프레드시트 확장 프로그램 > Apps Script 클릭
  • 2. 아래 템플릿 코드를 붙여넣고 저장(Ctrl+S)
  • 3. 우측 상단 [배포] > [새 배포] 선택
  • 4. 유형: 웹 앱 선택
  • 5. 다음 사용자 권한으로 실행: 나(me)
  • 6. ★액세스 권한: 모든 사용자(Anyone) (※'나만'으로 두면 Failed to fetch 발생!)
  • 7. 배포 후 발급되는 /exec URL을 복사하여 연동 탭에 입력
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  // A열: 학생이름, B열: 역할이름, C열: 아이콘, D열: 설명
  var students = [];
  var roles = [];
  for (var i = 1; i < data.length; i++) {
    var studentName = data[i][0] ? String(data[i][0]).trim() : '';
    var roleName = data[i][1] ? String(data[i][1]).trim() : '';
    if (studentName) students.push(studentName);
    if (roleName) {
      roles.push({
        id: i,
        name: roleName,
        icon: data[i][2] ? String(data[i][2]).trim() : '✨',
        desc: data[i][3] ? String(data[i][3]).trim() : '우리 반을 위해 책임을 다합니다.'
      });
    }
  }
  
  var payload = JSON.stringify({
    students: students,
    roles: roles
  });

  // JSONP 지원 (callback 파라미터가 있을 경우 CORS 문제 원천 방지)
  if (e && e.parameter && e.parameter.callback) {
    return ContentService.createTextOutput(e.parameter.callback + '(' + payload + ')')
           .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }

  return ContentService.createTextOutput(payload)
         .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('배정결과')
              || SpreadsheetApp.getActiveSpreadsheet().insertSheet('배정결과');
  sheet.clear();
  sheet.appendRow(['번호', '학생 이름', '역할', '아이콘', '설명', '배정일시']);
  data.assignments.forEach(function(item) {
    sheet.appendRow([item.number, item.studentName, item.role.name, item.role.icon, item.role.desc, new Date()]);
  });
  return ContentService.createTextOutput(JSON.stringify({ status: 'success' }))
         .setMimeType(ContentService.MimeType.JSON);
}
